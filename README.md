# Jack叔叔skill

一个基于 Jack要加油（抖音号 `JackandLinda`）公开内容整理的非官方 Codex Skill。它用于解释“六年之约”，并把学习、拖延和长期目标等问题拆成可执行的行动与复盘。

**身份声明：**本仓库与 Jack、Linda 及其团队无关联，未经其授权或认可；Skill 不代表本人发言，也不会冒充本人。所链接的公开视频及第三方作品归各自权利人所有。

## 安装与使用

将整个 `jack-uncle-skill` 文件夹放进 Codex 的技能目录（例如 Windows 的 `%USERPROFILE%\.codex\skills\`，或其他系统的 `~/.codex/skills/`）。保留 `SKILL.md`、`agents/` 和 `references/` 的原有层级，然后刷新技能列表或重启 Codex。

可这样提问：

- `用 $jack-uncle-skill 解释“六年之约”是什么，区分本人来源和粉丝转述。`
- `用 $jack-uncle-skill 帮我把学习目标拆成这周和今天能做的动作。`
